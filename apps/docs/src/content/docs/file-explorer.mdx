## Usage

Give it a tree of folders (nodes with `children`) and files. Each folder opens in the next column; the selected file shows in the preview pane.

```tsx
import { FileExplorer } from "@/components/mpkcn/file-explorer";

const tree = [
  {
    name: "projects",
    children: [
      {
        name: "atlas",
        meta: "2026",
        description: "A map viewer that works offline.",
        image: { src: "/shots/atlas.png", alt: "Atlas map view" },
        details: [
          { label: "status", value: "shipped" },
          { label: "stack", value: "Next.js, MapLibre" },
        ],
        href: "https://atlas.example.com",
      },
    ],
  },
  { name: "readme.md", description: "Hello." },
];

export function Projects() {
  return <FileExplorer items={tree} defaultPath={["projects", "atlas"]} />;
}
```

The built-in preview shows `image`, the name, `description`, `details` and an `href` link. Give one file a `preview` to replace it, or pass `renderPreview` to draw every preview yourself.

## Examples

### Open a file

`onOpen` runs on Enter or double click on a file, and adds an "open" button to the preview. In the demo above it opens the project pictures in a [Media Lightbox](/docs/components/media-lightbox/).

```tsx
<FileExplorer items={tree} onOpen={(node) => router.push(`/work/${node.id}`)} />
```

### Narrow widths

Below 672px of its own width (a container query), it shows one column at a time above the preview, with a `‹ ..` button to go back up.

`FileNode` is `{ name; id?; meta?; children?; keywords?; description?; image?: { src; alt? }; details?: { label; value }[]; href?; preview? }`. `id` defaults to `name` and only needs to be unique among its siblings.

## Accessibility

- Each column is a `listbox` named after its folder, and each row an `option` with `aria-selected`. Only the selected row of each column is in the Tab order, so Tab moves from column to column and then into the preview.
- ↑ ↓ Home End move, → or Enter go into a folder (Enter on a file calls `onOpen`, → moves to the preview), ← or Esc go back. / opens the filter; Esc clears it and Enter jumps to the results. The match count is a `status` region.
- The preview is a labelled region you can focus and scroll with the keyboard.
- The picture wipe and the blinking row cursor are skipped under `prefers-reduced-motion`.
