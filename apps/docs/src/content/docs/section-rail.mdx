## Usage

Render it once on a long page and list your section ids in order:

```tsx
import { SectionRail } from "@/components/mpkcn/section-rail";

export default function Page() {
  return (
    <>
      <SectionRail sections={["hero", "work", "about", "stack", "contact"]} className="hidden lg:flex" />
      <section id="hero">…</section>
      <section id="work">…</section>
      {/* … */}
    </>
  );
}
```

By default the rail is fixed to the middle of the right edge. A section becomes active once its top passes 40% of the viewport height; the active row shows its number and a filled blue dot. Clicking a row smooth-scrolls to its section.

## Examples

### Labels

Pass objects to give each link a readable name (the id is used otherwise):

```tsx
<SectionRail
  sections={[
    { id: "hero", label: "Top" },
    { id: "work", label: "Selected work" },
    { id: "contact", label: "Contact" },
  ]}
/>
```

### Inside a scroll container

Pass the container as `root`, and `fixed={false}` to place the rail yourself. This is how the preview above works.

```tsx
"use client";

import { useRef } from "react";
import { SectionRail } from "@/components/mpkcn/section-rail";

export function Panel() {
  const box = useRef<HTMLDivElement>(null);
  return (
    <div className="relative h-80">
      <div ref={box} className="h-full overflow-y-auto">
        <section id="a">…</section>
        <section id="b">…</section>
      </div>
      <SectionRail sections={["a", "b"]} root={box} fixed={false} className="absolute top-1/2 right-3 -translate-y-1/2" />
    </div>
  );
}
```

### React to the active section

```tsx
<SectionRail sections={ids} onActiveChange={(id) => setTitle(id)} />
```

## Accessibility

- A `nav` landmark (named "Sections" by default) of real links to `#id`, so it works without JavaScript and with the keyboard. Each link has a visible focus ring, and focusing it shows its number.
- Each link is named by its `label` (or id). The active one carries `aria-current="location"`.
- Under `prefers-reduced-motion: reduce` clicks jump instead of smooth-scrolling, and the dot and number transitions are off.
- It renders the first section as active on the server and measures after mount, so there is no hydration mismatch.
