## Usage

Pass ASCII art and the rows. The header reads `user@host`.

```tsx
import { FetchCard } from "@/components/mpkcn/fetch-card";

const ART = `
  /\\_/\\
 ( o.o )
  > ^ <`;

export function About() {
  return (
    <FetchCard
      art={ART}
      artLabel="A cat"
      user="you"
      host="portfolio"
      rows={[
        { label: "role", value: "full-stack developer" },
        { label: "stack", value: "Next.js · React · TypeScript" },
        { label: "loc", value: "Earth" },
      ]}
    />
  );
}
```

A string `art` is split into lines that slide in one after another. Leading and trailing blank lines are trimmed, so you can start the template literal on a new line. Set its size with `artClassName` (block-letter logos usually need `text-[9px]` to `text-[11px]`).

Any other node works as art too: an `<img>`, an SVG, an `AsciiImage`.

### Your own header

`title` replaces the `user@host` line, for a name or a link.

```tsx
<FetchCard title={<a href="/about">read more</a>} rows={rows} art={ART} />
```

## Accessibility

- The rows are a description list, so each label is tied to its value.
- ASCII art is noise to a screen reader: it is hidden unless you give it an `artLabel`, which turns it into an image with that name.
- The palette strip and the rule under the header are decorative and hidden.
- Under `prefers-reduced-motion: reduce` nothing slides and the art does not tilt. Touch input never tilts it.
