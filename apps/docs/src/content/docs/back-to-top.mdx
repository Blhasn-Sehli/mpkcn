## Usage

Render it once, in your root layout. A small square button fades in at the bottom right after the reader scrolls past most of the first screen.

```tsx
import { BackToTop } from "@/components/mpkcn/back-to-top";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <main id="main">{children}</main>
        <BackToTop focusSelector="#main" />
      </body>
    </html>
  );
}
```

## Accessibility

- It is a real `button` with an `aria-label` and a visible focus outline.
- While hidden it is `inert`: out of the tab order and the accessibility tree, so no one tabs onto an invisible control.
- Scrolling is smooth by default and jumps instantly under `prefers-reduced-motion: reduce`. The fade-in also turns off.
- Use `focusSelector` to move keyboard focus to the top of the page after scrolling; otherwise focus would land on `body` once the button hides. Elements that are not focusable get `tabindex="-1"` first.
