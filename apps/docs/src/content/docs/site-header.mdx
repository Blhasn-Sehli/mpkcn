## Usage

A sticky top bar: your logo on the left, numbered links in the middle, your own buttons on the right. Tell it which link is `current`.

```tsx
"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { SiteHeader } from "@/components/mpkcn/site-header";
import { ThemeToggle } from "@/components/mpkcn/theme-toggle";

export function Header() {
  const pathname = usePathname();
  return (
    <SiteHeader
      logo="mysite"
      linkComponent={Link}
      links={[
        { label: "home", href: "/" },
        { label: "docs", href: "/docs" },
        { label: "blog", href: "/blog" },
      ]}
      current={pathname}
      actions={<ThemeToggle />}
    />
  );
}
```

`current` is compared with each link's `id`, then its `href`, then its `label`. Pass next/link's `Link` as `linkComponent` for client-side navigation; without it, links are plain `<a>`.

## Accessibility

- Links sit in a `<nav>` landmark with a list; the active one has `aria-current="page"`. Every link and button has a visible amber focus ring.
- The menu button has `aria-expanded` and `aria-controls`. Opening the menu focuses its first link; Escape closes it and puts focus back on the button, and so does a click outside.
- The cursor stops blinking, the active marker stops sliding and the header stops sliding away under `prefers-reduced-motion`.
