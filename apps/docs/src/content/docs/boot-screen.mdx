## Usage

Render it once, at the top of your root layout. By default it covers the whole page as a fixed overlay, plays once per browser session, then removes itself.

```tsx
import { BootScreen } from "@/components/mpkcn/boot-screen";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <BootScreen user="mpk" host="mpk.dev" />
        {children}
      </body>
    </html>
  );
}
```

The sequence: a clock at the top, a login box with the title set in its border, the username typed in, password dots, `authenticating…`, then an optional matrix rain and a fade out. Any key or click skips straight to the end.

## Examples

### Inside a box

Pass `fullscreen={false}` to fill the nearest positioned parent instead of the viewport. Give the parent `position: relative` and a height. Change `key` to replay it.

<ComponentPreview

}`}

### Run code when it ends

`onDone` fires once when the screen finishes, is skipped, or is not shown at all (already seen this session, or reduced motion). Use it to start your own intro animations.

```tsx
"use client";

import { useState } from "react";
import { BootScreen } from "@/components/mpkcn/boot-screen";

export function Intro({ children }: { children: React.ReactNode }) {
  const [ready, setReady] = useState(false);
  return (
    <>
      <BootScreen onDone={() => setReady(true)} />
      <div data-ready={ready}>{children}</div>
    </>
  );
}
```

## Accessibility

- Under `prefers-reduced-motion: reduce` the screen is skipped entirely and `onDone` fires right away, unless `ignoreReducedMotion` is set (the previews on this site only set it after you click "play anyway").
- Any key or pointer press skips it. In fullscreen mode it listens on the window; inside a box, only on itself.
- Inside a box it is a focusable `button` labelled "Boot screen. Press any key or click to skip.", with a visible focus ring.
- Once finished it is `aria-hidden`, fades out and unmounts, so it never traps focus or hides content from screen readers.
- The box-drawing corners and the matrix canvas are decorative and hidden from assistive technology.
