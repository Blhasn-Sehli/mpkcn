## Usage

Render it once, in your root layout or on long pages. It pins a thin bar to the top of the viewport that fills as the page is scrolled.

```tsx
import { ScrollProgress } from "@/components/mpkcn/scroll-progress";

export default function ArticleLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      <ScrollProgress />
      <article>{children}</article>
    </>
  );
}
```

Updates are batched to one per frame, and the bar moves with `transform`, so it never triggers layout. It also follows content that grows or shrinks.

## Accessibility

- The bar is decorative: `aria-hidden` and `pointer-events: none`. The browser's own scrollbar still carries the position for assistive technology.
- It follows the scroll position directly, with no easing or animation, so nothing changes under reduced motion.
