## Usage

Put it first inside a positioned section, like a hero. It fills that parent behind the content.

```tsx
import { SceneCanvas } from "@/components/mpkcn/scene-canvas";

export function Hero() {
  return (
    <section className="relative isolate min-h-[70vh] overflow-hidden">
      <SceneCanvas />
      <div className="relative">
        <h1>Hello, world.</h1>
      </div>
    </section>
  );
}
```

A grid of dots with a slow wave running through it, in the current accent. The grid shifts a few pixels with the pointer. It follows the theme: switching dark and light redraws it in the new color.

### Kept light on the CPU

- Capped at 30 frames per second, one path and one fill per opacity level (6 in all) instead of one per dot.
- Stops drawing while it is off screen (IntersectionObserver) or the tab is hidden, and starts again when it is back.
- Draws one still frame under reduced motion, on low-power devices (4 cores or fewer, 4 GB memory or less, Save-Data on, or `<html data-perf="low">`), and on any device whose first 60 frames run well below the cap.
- Pixel density is capped at 1.5×. Raise `spacing` to draw fewer dots.

## Examples

### Page background

Pass `fullscreen` to cover the viewport behind the whole page (fixed, `-z-10`).

```tsx
<body>
  <SceneCanvas fullscreen opacity={0.08} />
  {children}
</body>
```

## Accessibility

- The canvas is decorative: `aria-hidden` and `pointer-events: none`.
- Under `prefers-reduced-motion: reduce` it draws one still frame and never animates, unless `ignoreReducedMotion` is set (the previews on this site only set it after you click "play anyway").
- Keep `opacity` low behind text so contrast is not affected.
