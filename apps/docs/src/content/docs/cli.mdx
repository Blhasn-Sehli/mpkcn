## Usage

Run it with `npx`, no install needed. It requires Node.js 22 or newer and has no runtime dependencies.

```bash
npx mpkcn <command> [options]
```

The usual flow is two commands:

```bash
npx mpkcn init
npx mpkcn add boot-screen
```

## init

Sets up your project once:

```bash
npx mpkcn init
```

`init`:

- writes `mpkcn-theme.css` to the components folder (skipped if it is already there);
- adds `@import "<relative path>/mpkcn-theme.css";` to your global CSS, right after `@import "tailwindcss"`. It never adds it twice;
- checks `package.json` for React 19, Tailwind CSS 4 and next-themes, and prints a `warn` line with the fix for anything missing or too old.

It looks for the global CSS at the usual Next.js and Vite paths (`src/app/globals.css`, `app/globals.css`, `src/styles/globals.css`, `src/index.css`, …), then in any CSS file that has `@import "tailwindcss"`. Pass `--css <path>` to choose the file. If none is found, it prints the exact line to add.

You can skip `init`: the first `add` runs the same steps, and only prints the warnings.

## add

Copies one or more components, plus everything they depend on, into your project:

```bash
npx mpkcn add boot-screen
npx mpkcn add theme-toggle reveal
```

For each item, `add`:

- resolves its `registryDependencies` (every component pulls in `theme`, the `mpkcn-theme.css` file);
- writes the files to the target folder, keeping sub-folders such as `lib/matrix-rain.ts`;
- skips files that already exist, unless you pass `--overwrite`;
- installs the npm packages your `package.json` does not list yet, with the package manager it detects (the `packageManager` field, then `pnpm-lock.yaml`, `yarn.lock`, `bun.lock` or `package-lock.json`; npm otherwise). The install output streams to your terminal;
- ends with the import line to paste, using the `@/` alias when your `tsconfig.json` has it.

```txt
Adding theme-toggle
  created     src/components/mpkcn/theme-toggle.tsx

Installing dependencies
  npm install next-themes
  (npm output)

Done. Use it:
  import { ThemeToggle } from "@/components/mpkcn/theme-toggle";
```

If the install fails, `add` prints the command to run yourself and exits with code 1. The files stay in place.

Item names must match `[a-z0-9-]+`. Every file target is checked before anything is written: absolute paths and paths that leave the target folder are rejected. npm package names from the registry are checked too before they reach your package manager.

## list

Shows every item in the registry with its description:

```bash
npx mpkcn list
```

## Options

| Option | Description | Default |
| --- | --- | --- |
| `-d, --dir <path>` | Folder the files are written to | `src/components/mpkcn`, or `components/mpkcn` without `src/` |
| `-c, --css <path>` | Global CSS file to add the theme `@import` to | auto-detected |
| `-r, --registry <url>` | Registry URL, or a local folder | `https://blhasn-sehli.github.io/mpkcn/r` |
| `-o, --overwrite` | Replace files that already exist | off |
| `--no-install` | Do not install npm packages, only print the command | off |
| `-y, --yes` | Non-interactive (mpkcn never prompts; accepted for scripts) | off |
| `-h, --help` | Show usage | |
| `-v, --version` | Show the version | |

### --dir

```bash
npx mpkcn add reveal --dir app/ui/terminal
```

### --css

```bash
npx mpkcn init --css src/styles/main.css
```

### --no-install

Useful in CI or when you manage dependencies yourself:

```bash
npx mpkcn add reveal --no-install
```

```txt
Install the npm dependencies:
  npm install framer-motion
```

### --registry

Point the CLI at another registry, such as a fork of mpkcn or a local build of this site:

```bash
npx mpkcn add boot-screen --registry https://example.com/r
npx mpkcn add boot-screen --registry ./apps/docs/public/r
```

## Registry format

The registry is a set of static JSON files served by this site:

| File | Content |
| --- | --- |
| `/r/index.json` | `{ name, title, description }[]` |
| `/r/<name>.json` | `{ name, title, description, dependencies, registryDependencies, files: { target, content }[] }` |

Anyone can host a compatible registry: any static file host that serves these two shapes works with `--registry`.
