## Usage

```tsx
import { ThemeToggle } from "@/components/mpkcn/theme-toggle";

export function Header() {
  return (
    <header className="flex items-center justify-between border-b border-mpk-line px-6 py-3">
      <span className="font-mpk-mono">mpkcn</span>
      <ThemeToggle />
    </header>
  );
}
```

It reads `resolvedTheme` and switches between `dark` and `light`. Until it has mounted it renders an invisible placeholder of the same size, so there is no hydration mismatch and no layout shift.

## Accessibility

- It is a native `button` with an `aria-label` and `title` that name the action, e.g. "Switch to light theme".
- The icons are `aria-hidden`; the label carries the meaning.
- Focus is visible with a 1px amber outline.
- The icon spin and hover lift are turned off under `prefers-reduced-motion`.
