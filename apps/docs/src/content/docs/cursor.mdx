## Usage

Render it once, in your root layout. By default it follows the pointer across the whole window as a fixed layer that never catches clicks.

```tsx
import { Cursor } from "@/components/mpkcn/cursor";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        <Cursor />
        {children}
      </body>
    </html>
  );
}
```

A small amber block sits on the pointer and a square ring trails behind it. Mark buttons or links with `data-magnetic` and they lean toward the pointer while the ring grows and turns blue.

```tsx
<button data-magnetic>deploy</button>
```

### Hide the system cursor

`hideNativeCursor` hides the system arrow while the custom cursor is visible. Text fields (inputs, textareas, selects and `contenteditable`) always keep the system I-beam, and the custom cursor steps aside over them.

```tsx
<Cursor hideNativeCursor />
```

### No magnets, snappier ring

```tsx
<Cursor magnetic={false} lag={0.35} />
```

## Accessibility

- It only runs for a real mouse: on touch screens and coarse pointers (`hover: none`, `pointer: coarse`) it never starts, and pen or touch events are ignored.
- Under `prefers-reduced-motion: reduce` and on low-power devices (4 cores or fewer, 4 GB memory or less, Save-Data on, or `<html data-perf="low">`) it stays off, unless `ignoreReducedMotion` is set.
- Over text fields it hides itself and the system I-beam and caret stay. Pressing Tab, or typing in a field, hides it until the mouse moves again, so the focus ring is never covered.
- It is `aria-hidden`, has `pointer-events: none`, and the ring only animates while it is catching up, so it costs nothing when the mouse is still.
