## Usage

```tsx
import { ImagePlaceholder } from "@/components/mpkcn/image-placeholder";

export function ProjectCard() {
  return <ImagePlaceholder src="/images/dashboard.png" alt="Dashboard, dark theme" className="w-full" />;
}
```

While `src` is empty, or if the file fails to load, the box shows faint diagonal stripes and a mono label in the corner. Once the image loads it fills the frame (`object-fit: cover`). So you can lay out a page before the screenshots exist, then drop the files in.

### Size it yourself

`aspectRatio={null}` drops the built-in ratio so your classes decide the size.

```tsx
<ImagePlaceholder alt="Avatar" aspectRatio={null} className="size-24" label="" />
```

### With next/image

The component uses a plain `<img>` so it works in any React app. In Next.js you can swap that tag for `next/image` with `fill` in your copy of the file.

## Accessibility

- With an image, the `<img>` carries your `alt` text as usual.
- Without one, the box is `role="img"` named by the same `alt`, so screen readers still know what belongs there. The stripes and the corner label are `aria-hidden`.
- A load error that happens before hydration is caught too, so a broken URL never shows the browser's broken-image icon for long.
