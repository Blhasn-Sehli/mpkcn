## Usage

```tsx
import { LetterReveal } from "@/components/mpkcn/letter-reveal";

export function Hero() {
  return <LetterReveal as="h1" text="Hello, terminal." className="text-5xl font-semibold" />;
}
```

Each letter starts 0.7em low, tilted back 80°, and springs into place (stiffness 260, damping 18), 35ms after the one before it. Words never break in the middle. Hovering a letter lifts it and turns it blue.

### Replay on every scroll

`trigger="view"` plays the reveal each time the text comes back into view.

```tsx
<LetterReveal as="h2" text="Selected work" trigger="view" />
```

### Wait for an intro

`play={false}` keeps the letters hidden until you flip it, for example when a [Boot Screen](/docs/components/boot-screen/) finishes:

```tsx
"use client";

import { useState } from "react";
import { BootScreen } from "@/components/mpkcn/boot-screen";
import { LetterReveal } from "@/components/mpkcn/letter-reveal";

export function Hero() {
  const [booted, setBooted] = useState(false);
  return (
    <>
      <BootScreen onDone={() => setBooted(true)} />
      <LetterReveal as="h1" text="Hello, terminal." play={booted} delay={0.2} />
    </>
  );
}
```

## Accessibility

- Screen readers read the text once, whole, from a visually hidden copy. The letter spans are `aria-hidden`, so the heading is never spelled out letter by letter.
- Under `prefers-reduced-motion: reduce` nothing moves or flips: the letters only fade in, and the hover hop is reduced to the color change.
- Server and client render the same markup, so there is no hydration mismatch.

<Callout type="warn">
  The letters start at opacity 0 until JavaScript runs. The hidden copy keeps the text available to screen readers and search engines, but sighted users without JavaScript see an empty heading.
</Callout>
