## 0.4.0

CLI `mpkcn@0.3.0`: no manual steps left, 11 new components (35 in total), and setup from your AI assistant.

- **New components:** `site-header`, `prompt-footer`, `file-explorer`, `scroll-hint` (Navigation); `case-card`, `tech-stack`, `arch-diagram` (Cards); `media-lightbox`, `parallax-image` (Media); `fetch-card`, `env-card` (Terminal).

- **Theme provider:** new `theme-provider` item, `MpkcnThemeProvider` (next-themes with `attribute="class"`, dark first, dark and light only, no transition flash). `theme-toggle` depends on it, and the CLI wraps your root layout in it and adds `suppressHydrationWarning` to `<html>`.
- **Fonts:** in a Next.js app the CLI loads Space Grotesk and JetBrains Mono with `next/font` in your root layout. The theme's `--font-mpk-sans` / `--font-mpk-mono` now read the `next/font` variables first, then the font names and system fonts, so existing setups keep working. A 0.2 theme file is upgraded in place when its font lines are untouched.
- **Safe edits:** the layout is only edited when it has the simple `create-next-app` shape; a layout that already has a `ThemeProvider` or the fonts is left alone, and anything unusual gets the exact lines to paste instead. Every edit is idempotent and shows as one `updated` line.
- **Flags:** `--no-layout` never edits the layout, `--no-fonts` skips the fonts.
- **Other frameworks:** without Next.js nothing is edited; the CLI prints where to put the provider and a Google Fonts `@import` line.
- **`init`:** in a Next.js app it also sets up the provider and fonts, and checks both.
- **Docs:** [Installation](/docs/installation/) is now one command, with the manual steps kept below it.
- **Use with AI:** `mpkcn mcp` is an MCP server for Claude Code, Cursor, VS Code, Windsurf and Claude Desktop, with four tools: `list_components`, `get_component`, `add_components` and `init_project`. Setup is one line: `claude mcp add mpkcn -- npx -y mpkcn@latest mcp`. Hand-written on stdio, so the CLI still has no runtime dependencies. See [Use with AI](/docs/ai/).
- **llms.txt:** the site publishes [`llms.txt`](https://blhasn-sehli.github.io/mpkcn/llms.txt) and [`llms-full.txt`](https://blhasn-sehli.github.io/mpkcn/llms-full.txt), built from the registry and the docs. The registry JSON now also carries each item's category, docs URL and usage example.

## 0.3.0

CLI `mpkcn@0.2.0`: one command, no manual steps.

- **`mpkcn init`:** writes `mpkcn-theme.css`, adds its `@import` to your global CSS and checks `package.json` for React 19, Tailwind CSS 4 and next-themes, with the fix for anything missing.
- **Automatic install:** `mpkcn add` installs the npm packages a component needs with your package manager (npm, pnpm, yarn or bun) and skips packages already in `package.json`. `--no-install` only prints the command.
- **Automatic theme import:** the first `add` finds your global CSS (`src/app/globals.css`, `src/index.css`, … or any file that imports Tailwind) and adds the theme `@import` right after `@import "tailwindcss"`, once. `--css <path>` picks the file.
- **Next step:** `add` ends with the import line to paste, using the `@/` alias when `tsconfig.json` has it.
- **Docs:** [Installation](/docs/installation/) is now `npx mpkcn init`, then `npx mpkcn add <name>`, with the manual steps kept as a fallback.

## 0.2.0

21 new components and a gallery to browse them all.

- **Gallery:** [/components](/components/) shows every component running live, with search, category filters, the full source and a copy button for the install command.
- **Terminal:** `terminal-window`, `terminal-shell`, `command-palette`, `shortcuts-dialog`, `tmux-bar`, `terminal-form`, `konami`.

- **Text & layout:** `kbd`, `eyebrow`, `section-divider`, `section-rail`, `image-placeholder`, `feature-list`, `scroll-progress`, `back-to-top`.
- **Accessibility:** every animated component respects `prefers-reduced-motion` and has an `ignoreReducedMotion` escape hatch; dialogs trap and return focus.
- **CLI:** unchanged (`mpkcn@0.1.0` installs every new component).

## 0.1.0

First release.

- **Components:** `boot-screen`, `theme-toggle` and `reveal`, each with dark and light support and `prefers-reduced-motion` handling.
- **Theme:** `mpkcn-theme.css` with eight `--mpk-*` tokens, two font stacks and the blink animation, as Tailwind 4 theme variables.
- **CLI:** `mpkcn add` and `mpkcn list`, with `--dir`, `--registry` and `--overwrite`. Requires Node.js 22 or newer.
- **Registry:** static JSON at `/r/index.json` and `/r/<name>.json`.
- **Tested with:** React `19.3.0`, Next.js `16.4.5`, Tailwind CSS `4.x`, next-themes `0.4.6`, framer-motion `13.4.4`.
