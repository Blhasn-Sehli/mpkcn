## 0.2.0

21 new components and a gallery to browse them all.

- **Gallery:** [/components](/components/) shows every component running live, with search, category filters, the full source and a copy button for the install command.
- **Terminal:** `terminal-window`, `terminal-shell`, `command-palette`, `shortcuts-dialog`, `tmux-bar`, `terminal-form`, `konami`.
- **Effects:** `cursor`, `grain`, `spotlight`, `scene-canvas`, `ascii-image`, `letter-reveal`.
- **Text & layout:** `kbd`, `eyebrow`, `section-divider`, `section-rail`, `image-placeholder`, `feature-list`, `scroll-progress`, `back-to-top`.
- **Accessibility:** every animated component respects `prefers-reduced-motion` and has an `ignoreReducedMotion` escape hatch; dialogs trap and return focus.
- **CLI:** unchanged (`mpkcn@0.1.0` installs every new component).

## 0.1.0

First release.

- **Components:** `boot-screen`, `theme-toggle` and `reveal`, each with dark and light support and `prefers-reduced-motion` handling.
- **Theme:** `mpkcn-theme.css` with eight `--mpk-*` tokens, two font stacks and the blink animation, as Tailwind 4 theme variables.
- **CLI:** `mpkcn add` and `mpkcn list`, with `--dir`, `--registry` and `--overwrite`. Requires Node.js 22 or newer.
- **Registry:** static JSON at `/r/index.json` and `/r/<name>.json`.
- **Tested with:** React `19.3.0`, Next.js `16.4.5`, Tailwind CSS `4.x`, next-themes `0.4.6`, framer-motion `13.4.4`.
