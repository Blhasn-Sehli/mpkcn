## Usage

Render it once, in your root layout. It covers the whole viewport as a fixed layer above the page and never catches clicks. It has no state, so it also works in a Server Component.

```tsx
import { Grain } from "@/components/mpkcn/grain";

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" suppressHydrationWarning>
      <body>
        {children}
        <Grain />
      </body>
    </html>
  );
}
```

The noise is two layers of the same SVG tile: a `screen` layer that lifts dark pixels and a `multiply` layer that darkens light ones. A single `overlay` layer almost disappears on a near-black background; the pair stays visible on both themes. The tile is a background image, so it is drawn once and costs nothing per frame.

## Examples

### Inside a box

Pass `contained` to fill the nearest positioned parent instead of the viewport. Add `isolate` to the parent to blend only with what is inside it.

## Accessibility

- Both layers are `aria-hidden` and `pointer-events: none`: nothing to read, nothing to click through.
- The grain is static, so there is nothing to turn off for reduced motion.
- The default strength (4% and 2% on dark, 2% and 5% on light) is a texture, not a filter: text contrast stays the same. Keep `intensity` low over body text.
- It is hidden when printing.
