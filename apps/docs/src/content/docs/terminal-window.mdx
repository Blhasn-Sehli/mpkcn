## Usage

Pass the lines to type. Each line is a `command` typed after the prompt, then its `output`. Typing starts when the window scrolls into view.

```tsx
import { TerminalWindow } from "@/components/mpkcn/terminal-window";

export function Install() {
  return (
    <TerminalWindow
      title="~/app — zsh"
      lines={[
        { command: "npx mpkcn add boot-screen", output: "✓ created boot-screen.tsx" },
        { command: "pnpm dev", output: "ready on http://localhost:3000" },
      ]}
    />
  );
}
```

Outputs are React nodes, so they can hold colors, links or whole components. Change the window's `key` to replay the typing.

### Just the chrome

With no `lines`, it is a plain window frame: set `idlePrompt={false}` and put anything inside. Add `onClose` for an "esc" button, or `actions` for your own.

```tsx
<TerminalWindow title="preview.tsx" idlePrompt={false} onClose={() => setOpen(false)}>
  <pre>{code}</pre>
</TerminalWindow>
```

## Accessibility

- Under `prefers-reduced-motion: reduce` every line appears at once, and the cursor stops blinking.
- Screen readers get each command in full, never half-typed: the typed text is hidden from them and a visually hidden copy carries the whole command.
- The dots are decorative and hidden. The close button is a real `button` labelled "Close" with a visible focus ring.
- Content passed as `children` only mounts after the typing, so do not put anything there that must be reachable before it finishes.
