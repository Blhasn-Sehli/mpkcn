## Usage

A footer that reads like a shell session. `ls` prints your link columns, `date` your copyright, and the last prompt waits with a blinking cursor.

```tsx
import Link from "next/link";
import { PromptFooter } from "@/components/mpkcn/prompt-footer";

export function Footer() {
  return (
    <PromptFooter
      user="guest"
      host="mysite.dev"
      linkComponent={Link}
      groups={[
        { title: "sections", links: [{ label: "docs", href: "/docs" }, { label: "blog", href: "/blog" }] },
        { title: "elsewhere", links: [{ label: "github", href: "https://github.com/you" }] },
      ]}
      owner="Your Name"
      note="built with Next.js"
    />
  );
}
```

Links that start with `http` open in a new tab. Internal links use `linkComponent` when you pass one (next/link fits), plain `<a>` otherwise.

## Examples

### Now block and clock

`now` prints a few `label: value` lines as `cat now.txt`. `clock` adds a live HH:MM:SS clock on the date line; with `timeZone` and `clockLabel` it can show your own local time.

### Your own last line

Anything you pass as `children` replaces the cursor after the last prompt, for example a status or a small input.

## Accessibility

- It renders a `<footer>` landmark. Links sit in a `<nav aria-label="Footer">` as plain lists, so the `›` markers are hidden from screen readers.
- External links say "(opens in a new tab)" to screen readers. The `now` lines are a description list.
- The clock is not a live region and renders `--:--:--` on the server, so it never interrupts a screen reader and never causes a hydration mismatch.
- The cursor stops blinking under `prefers-reduced-motion`, and the back-to-top button jumps instead of scrolling smoothly.
