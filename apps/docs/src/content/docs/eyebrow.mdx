## Usage

Put it right above a section heading:

```tsx
import { Eyebrow } from "@/components/mpkcn/eyebrow";

export function Work() {
  return (
    <section id="work">
      <Eyebrow text="// 02 — selected work" />
      <h2>Things I built</h2>
    </section>
  );
}
```

Each time the label scrolls into view (80% visible) it clears and types itself back in at 32ms per character, with a blinking block cursor. The server renders the full text, so it is there before JavaScript runs.

### Type once, slower

`replay={false}` types it only the first time; `speed` sets the milliseconds per character.

```tsx
<Eyebrow text="// 01 — about" replay={false} speed={60} />
```

### Static label

`typing={false}` keeps the style and drops the animation.

```tsx
<Eyebrow text="// changelog" typing={false} />
```

### As a heading

The default element is a `p`. Pass `as` when the label is part of your outline:

```tsx
<Eyebrow as="h2" text="// 03 — stack" className="mb-4" />
```

## Accessibility

- Screen readers get the full label once, from a visually hidden copy. The typed characters and the cursor are `aria-hidden`, so nothing is announced letter by letter.
- The untyped part of the text is still laid out (invisible), so the line never changes width or wraps differently while typing.
- Under `prefers-reduced-motion: reduce` the label is simply shown, with no typing and no cursor.
- Server and client render the same full text, so there is no hydration mismatch.
