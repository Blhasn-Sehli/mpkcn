## Usage

Give it an image and a size:

```tsx
import { AsciiImage } from "@/components/mpkcn/ascii-image";

export function Portrait() {
  return <AsciiImage src="/me.jpg" alt="Portrait of the author" className="aspect-[4/5] w-64" />;
}
```

Right after hydration the picture is covered by a wall of glyphs (`01<>/{}$#=+*`) in the blue accent. When the frame scrolls into view, each cell flickers, flashes bright and drops away in a noisy left-to-right sweep (1.8s), until only the photo is left. The canvas is then removed.

### Custom characters, start on load

```tsx
<AsciiImage src="/cover.png" alt="Album cover" chars="░▒▓█" trigger="mount" delay={600} className="size-72" />
```

### Wait for an intro

`play={false}` keeps the code wall up until you flip it, for example when a [Boot Screen](/docs/components/boot-screen/) ends:

```tsx
<AsciiImage src="/me.jpg" alt="Portrait" play={booted} className="aspect-[4/5] w-64" />
```

## Accessibility

- The real `<img>` with your `alt` text is always in the page, and it is what the server renders: without JavaScript you simply see the photo.
- The glyph canvas is decorative (`aria-hidden`) and is removed once the decode ends.
- Under `prefers-reduced-motion: reduce`, and on low-power devices, the effect is skipped and the photo shows straight away.
- Glyph colors are read from `--mpk-bg`, `--mpk-blue` and `--mpk-ink` when it starts, so it matches the current theme.
