## Usage

```tsx
import { FeatureList } from "@/components/mpkcn/feature-list";

export function ProjectFacts() {
  return (
    <FeatureList
      items={[
        { label: "Role", value: "Solo dev" },
        { label: "Stack", value: "Next.js · Postgres" },
        { label: "Year", value: "2026" },
      ]}
    />
  );
}
```

Each row is a label on the left (bright) and a value on the right (dimmed), between hairlines. When a third of the list is in view, the rows slide in from the left one by one, 80ms apart.

### Rich values

`label` and `value` take any React node, such as links or badges.

```tsx
<FeatureList
  items={[
    { label: "Repo", value: <a href="https://github.com/you/app">github.com/you/app</a> },
    { label: "Status", value: <span className="text-mpk-amber">beta</span> },
  ]}
/>
```

## Accessibility

- Rendered as a description list: each row is a `div` holding a `dt` (label) and a `dd` (value), so screen readers announce the pairs together.
- Under `prefers-reduced-motion: reduce` the rows don't slide, they only fade in.
- Server and client render the same markup, so there is no hydration mismatch.
