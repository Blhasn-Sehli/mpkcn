## Usage

Put it at the bottom of your hero. It fades out over the first 80px of scroll.

```tsx
import { ScrollHint } from "@/components/mpkcn/scroll-hint";

export function Hero() {
  return (
    <section className="relative h-dvh">
      {/* … */}
      <div className="absolute inset-x-0 bottom-8 flex justify-center">
        <ScrollHint target="#work" />
      </div>
    </section>
  );
}
```

With `target` it becomes a link that scrolls to that element and moves focus there. With only `onClick` it is a button. With neither it is purely decorative and hidden from screen readers.

## Examples

### Variants

`"line"` runs a block down a hairline, `"chevron"` bounces an arrow, `"mouse"` rolls a wheel. Use the buttons under the first preview to switch.

### Inside a scroll container

By default it watches the page. Pass `container` (a ref) to watch a scrolling element instead, as the previews do.

```tsx
const box = useRef<HTMLDivElement>(null);

<div ref={box} className="h-96 overflow-y-auto">
  <ScrollHint container={box} target="#next" scrollBlock="nearest" />
  …
</div>
```

## Accessibility

- As a link or a button it has the name "Scroll down" (change it with `ariaLabel`) and a visible focus ring. The label and the animation inside it are hidden from screen readers.
- After the scroll, focus moves to the target (it gets `tabindex="-1"` if it is not focusable), so keyboard users continue from there.
- Once it has faded out it ignores the pointer and leaves the tab order.
- Under `prefers-reduced-motion: reduce` the indicator holds still and the jump is instant instead of smooth.
