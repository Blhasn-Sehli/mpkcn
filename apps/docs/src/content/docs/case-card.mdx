## Usage

One card per project. Stack several in a list; each one draws a hairline above and below, so neighbours share a line.

```tsx
import { CaseCard } from "@/components/mpkcn/case-card";

export function Work() {
  return (
    <CaseCard
      index="01"
      title="Atlas"
      subtitle="Offline map viewer · 2026"
      description="Streams vector tiles and keeps working on a plane."
      tags={["Next.js", "MapLibre"]}
      links={[{ label: "code", href: "https://github.com/you/atlas", ariaLabel: "Atlas source code" }]}
      image={{ src: "/shots/atlas.png", alt: "Atlas map view" }}
      features={[
        { label: "Cache", value: "IndexedDB" },
        { label: "Bundle", value: "92 kB gz" },
      ]}
    />
  );
}
```

With `features`, the card splits into two columns once it is 768px wide (a container query, so it also stacks inside a narrow layout). Without them it stays one column.

## Accessibility

- Each card is an `<article>` with a real heading; pick `headingLevel` to fit your page outline.
- Tags are a list labelled "Tags", and features a description list, so each label is tied to its value.
- Give links an `ariaLabel` like "Atlas source code" when several cards share the same "code" label. External links also say "(opens in a new tab)".
- The placeholder is an image named by `image.alt`. Nothing in the card moves, so there is no motion to reduce.
